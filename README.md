# fluffy-barnacle

Krótki szablon repozytorium, który możesz od razu wykorzystać jako punkt startowy projektu.

## O projekcie

To repo zawiera podstawowe pliki organizacyjne:
- `README.md` z instrukcją uruchomienia,
- `LICENSE` z warunkami licencji MIT.

Uzupełnij sekcje poniżej o informacje specyficzne dla Twojej aplikacji.

## Wymagania

- Git
- (opcjonalnie) Docker
- narzędzia zależne od technologii projektu (np. Node.js / Python / Java)

## Start

1. Sklonuj repozytorium:

   ```bash
   git clone <URL_REPOZYTORIUM>
   cd fluffy-barnacle
   ```

2. Zainstaluj zależności projektu (uzupełnij zgodnie ze stackiem):

   ```bash
   # npm install
   # pip install -r requirements.txt
   ```

3. Uruchom aplikację lokalnie (uzupełnij):

   ```bash
   # npm run dev
   # python -m app
   ```

## Testowanie

Dodaj tutaj polecenia uruchamiania testów, np.:

```bash
# npm test
# pytest
```
